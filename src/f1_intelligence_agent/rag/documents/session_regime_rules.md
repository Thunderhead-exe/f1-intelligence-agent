# Session Regime Rules

Session-wide regimes should be separated from individual driver or lap anomalies. Rain transitions, wet tyres, safety-car periods, virtual-safety-car periods, yellow flags, red flags, race starts, restarts, and same-lap outliers across multiple drivers usually describe shared context.

A driver/lap anomaly should be prioritized when the unusual pattern is specific to one driver-lap after accounting for weather regime, compound regime, track status, pit laps, deleted laps, and timing quality.

When a finding is session-wide, report it as context and avoid turning it into a driver-specific hypothesis unless telemetry or official context supports that narrower claim.
