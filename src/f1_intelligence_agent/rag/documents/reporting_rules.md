# Reporting Rules

Separate evidence from hypothesis. State what the model or telemetry shows before offering a possible explanation.

Do not say that a driver made a mistake unless explicit context supports it. Prefer careful language such as "possible explanation", "likely pattern", "evidence suggests", and "should be validated".

Include a confidence level for each insight. Confidence should reflect evidence consistency and data quality, not model certainty alone.

Mention limitations. Unsupervised ML can rank unusual laps, but it cannot prove causality.

Tie each insight to at least one evidence source: model output, feature deviation, telemetry, weather, race control, retrieved context, web context, or validated memory.

Do not invent lap numbers, driver names, metrics, weather, penalties, flags, or telemetry patterns. Use only provided structured data.

Label Tavily or other web context as external context. Treat snippets as context, not ground truth.
